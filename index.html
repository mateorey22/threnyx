🕸️ MeshChat

La messagerie sans serveur. Ici, il n'y a aucun serveur central : vous êtes le réseau.

1Votre appareil devient un nœud P2P (WebRTC)
2Les données sont chiffrées (AES-256) puis répliquées sur le maillage
3Tant qu'un nœud est en ligne, le réseau survit
Comment ça marche techniquement ?
  • Réseau maillé : chaque contact ajouté ouvre un canal WebRTC direct. Les messages se propagent par Gossip Protocol à travers tous les nœuds.
  • Zero-Knowledge : tout est chiffré (ECDH + AES-GCM 256) avant de quitter votre appareil. Les nœuds relais ne stockent que des fragments illisibles.
  • Stockage distribué : l'historique est répliqué chiffré dans l'IndexedDB des autres utilisateurs.
  • 0 serveur : même l'ajout de contact se fait par échange manuel de codes d'invitation chiffrés (QR/lien) — aucune donnée ne transite ailleurs.
